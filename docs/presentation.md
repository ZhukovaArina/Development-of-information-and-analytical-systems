# Презентация: Университетская дата-платформа

## Слайд 1: Проблематика
- Разрозненные данные (LMS, CSV, события кампуса)
- Отсутствие единой аналитики
- Нет мониторинга в реальном времени

## Слайд 2: Архитектура решения
- Data Mesh: 3 домена (успеваемость, инфраструктура, вовлечённость)
- Data Lake: S3 + Parquet
- Lakehouse: Bronze → Silver → Gold
- Streaming: Kafka + ClickHouse
- Semantic Layer: Cube.js

## Слайд 3: ETL-пайплайны
- Airflow DAG для batch-загрузки
- Great Expectations для валидации
- Retry + алерты

## Слайд 4: Real-time аналитика
- Kafka для событий кампуса
- Потоковая агрегация (5-мин окна)
- ClickHouse для хранения
- Grafana/Streamlit для визуализации

## Слайд 5: ML-ready признаки
- Feature Store на Feast (Gold-слой)
- Признаки студента для прогноза успеваемости

## Слайд 6: Демонстрация
- Airflow: запуск DAG
- Kafka: генерация событий
- Streamlit: дашборд в реальном времени
- ClickHouse: аналитические запросы

## Слайд 7: Результаты
- Единая платформа для всех данных
- Real-time мониторинг кампуса
- Готовые признаки для ML
- Полный CI/CD пайплайн
